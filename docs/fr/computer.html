Depuis un ordinateur

Colle un prompt, ton agent IA fait le reste

Aucune appli à télécharger sur la TV : ton ordinateur lui parle par le Wi-Fi. Colle un de ces prompts dans Claude Code, Codex, Gemini CLI ou tout agent capable de lancer des commandes. Il installe ce qu'il lui faut, te montre ce qu'il a trouvé, demande avant de désactiver quoi que ce soit, et garde une trace pour tout remettre comme avant.

  1. Sur la TV, active le mode développeur et le débogage USB (étape 1 ici).
  2. Ton ordinateur est sur le même Wi-Fi que la TV.
  3. Tape l'adresse IP de ta TV ci-dessous : chaque prompt la reprend.
Sur la TV : Paramètres › Réseau et Internet › ton Wi-Fi.
1

Nettoyer ma TV

L'installation complète : pubs, pistage et superflu coupés, l'accueil OwnYourTV si tu le veux, les boutons de la télécommande qui marchent toujours.

Clone https://github.com/pimado1/ownyourtv et suis son PROMPT.md pour nettoyer ma TV. Demande-moi avant de désactiver quoi que ce soit et avant de changer l'accueil. L'adresse IP de ma TV est IP_DE_TA_TV.
2

Tout remettre comme avant

Chaque appli désactivée par OwnYourTV se rallume, et l'accueil d'origine de la TV revient. Rien n'a jamais été supprimé.

Clone https://github.com/pimado1/ownyourtv s'il n'est pas déjà là. Lance python3 ownyourtv.py IP_DE_TA_TV undo pour remettre tout ce qu'OwnYourTV a changé sur ma TV, montre-moi ce qui s'est rallumé, puis rappelle-moi de désactiver le débogage USB.
3

Une mise à jour de la TV a remis les pubs

Les mises à jour rallument parfois les applis du fabricant. L'agent les retrouve et les recoupe, avec ton accord.

Clone https://github.com/pimado1/ownyourtv s'il n'est pas déjà là. Lance python3 ownyourtv.py IP_DE_TA_TV list, dis-moi quelles applis désactivées par OwnYourTV sont rallumées, et ne les recoupe qu'après mon accord.

Sans agent IA

La même chose, tapée toi-même. Il te faut Python 3 et adb (les outils Android).

Installer adb sur macOS
brew install android-platform-tools
Installer adb sur Windows
winget install Google.PlatformTools
Récupérer OwnYourTV
git clone https://github.com/pimado1/ownyourtv && cd ownyourtv
Nettoyer, avec un menu
python3 ownyourtv.py YOUR_TV_IP
Le nettoyage recommandé d'un coup
python3 ownyourtv.py YOUR_TV_IP optimise
Tout remettre comme avant
python3 ownyourtv.py YOUR_TV_IP undo

Mêmes listes et mêmes règles de sécurité que l'appli TV : les applis sont désactivées, jamais supprimées, et ce dont la TV a besoin pour démarrer, lire une chaîne ou une entrée HDMI n'est jamais proposé. Quand c'est fini, désactive le débogage USB sur la TV.
