Privacy

OwnYourTV collects nothing. Here is exactly what leaves your TV, and when.

On your TV

The app connects to your own TV's debugging port (127.0.0.1) to switch apps off and change the home screen. Nothing from that connection leaves the TV. No account, no advertising, no analytics.

The weather

If you pick a city for the weather, its name (to find it) and then its coordinates are sent to Open-Meteo, a free weather service with no account. With no city picked, nothing is sent.

Updates

Once a day, OwnYourTV asks GitHub (api.github.com) for the number of its latest version. Nothing about your TV is sent; like any server, GitHub sees the request's IP address. If you choose to update, the new version is downloaded from GitHub.

Profiles and child mode

Profiles, the parent code and a child's screen time are kept on the TV and never sent. To keep a child to their apps, OwnYourTV uses Android's usage access to see which app is in front, never what is in it, and only while a child's profile is in use.

Sharing, only if you press Share

On the last screen, the Share button sends an anonymous report. The screen shows the line that is sent before you press it.

Where the report goes

It goes through a small relay hosted by Cloudflare, which keeps nothing: it checks the report and adds it to a public page on GitHub, one per TV model. Like any server, the relay sees the request's IP address, and only uses it to allow 5 reports a minute, without storing it. The report becomes public: it is the list of TVs OwnYourTV works on.

Removing a report

A report holds nothing that points to you. If you still want one removed, open an issue on GitHub naming the model.

The code is public

Everything described here can be checked in the code: what the app sends and what the relay does.
