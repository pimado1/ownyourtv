From a computer

Paste a prompt, your AI agent does the rest

No app to download on the TV: your computer talks to it over Wi-Fi. Paste one of these prompts into Claude Code, Codex, Gemini CLI or any agent that can run commands. It installs what it needs, shows you what it found, asks before switching anything off, and keeps a record so everything can be put back.

  1. On the TV, turn on developer mode and USB debugging (step 1 here).
  2. Your computer is on the same Wi-Fi as the TV.
  3. Type your TV's IP address below: every prompt fills it in.
On the TV: Settings › Network & Internet › your Wi-Fi.
1

Clean up my TV

The full install: ads, tracking and clutter off, the OwnYourTV home if you want it, the remote's buttons kept working.

Clone https://github.com/pimado1/ownyourtv and follow its PROMPT.md to clean up my TV. Ask me before switching anything off, and before changing the home screen. My TV's IP address is YOUR_TV_IP.
2

Put everything back

Every app OwnYourTV switched off comes back on, and the TV's original home screen returns. Nothing was ever deleted.

Clone https://github.com/pimado1/ownyourtv if it is not here yet. Run python3 ownyourtv.py YOUR_TV_IP undo to put back everything OwnYourTV changed on my TV, show me what came back on, then remind me to turn USB debugging off.
3

A TV update brought the ads back

Updates sometimes switch the maker's apps back on. The agent finds them and switches them off again, with your OK.

Clone https://github.com/pimado1/ownyourtv if it is not here yet. Run python3 ownyourtv.py YOUR_TV_IP list, tell me which apps are on again that OwnYourTV had switched off, and switch them off only after I say yes.

Without an AI agent

The same, typed yourself. You need Python 3 and adb (Android platform tools).

Install adb on macOS
brew install android-platform-tools
Install adb on Windows
winget install Google.PlatformTools
Get OwnYourTV
git clone https://github.com/pimado1/ownyourtv && cd ownyourtv
Clean up, with a menu
python3 ownyourtv.py YOUR_TV_IP
The recommended set in one go
python3 ownyourtv.py YOUR_TV_IP optimise
Put everything back
python3 ownyourtv.py YOUR_TV_IP undo

Same lists and same safety rules as the TV app: apps are switched off, never deleted, and what the TV needs to start, play a channel or an HDMI input is never offered. When you are done, turn USB debugging off on the TV.
